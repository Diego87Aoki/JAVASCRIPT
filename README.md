# 🔢 Tabuada do 0 ao 10 – HTML + JavaScript

Este projeto simples gera a **tabuada dos números de 0 a 10** utilizando apenas **HTML e JavaScript puro** (sem frameworks).

---

## 📄 Descrição

O programa exibe no navegador a tabuada completa de 0 a 10, com multiplicações de 1 até 10 para cada número. Ótimo exercício para iniciantes entenderem:

- Estrutura `while`
- Manipulação do DOM (`innerHTML`)
- Laços de repetição em JavaScript

---

## 💡 Pré-requisitos

- Navegador moderno (Chrome, Firefox, Edge etc.)
- Editor de texto (VS Code, Notepad++, etc.)

---

## 🚀 Como Executar

1. Baixe ou clone o repositório:

```bash
git clone https://github.com/SeuUsuario/NomeDoRepositorio.git
```

2. Abra o arquivo `index.html` no navegador (basta dar dois cliques).

3. Veja a tabuada exibida diretamente na tela.

---

## 🧠 Aprendizados

Com este projeto, você vai aprender:

- Como usar `while` para criar laços de repetição
- Como gerar conteúdo dinâmico com `innerHTML`
- Como organizar um projeto básico com HTML e JS
